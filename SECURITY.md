## Reporting a Vulnerability

Security is paramount in confidential computing protocols. If you discover a vulnerability or potential exploit regarding:
- FHE ciphertext handle leakage
- Re-entrancy or state desynchronization in GhostVault / GhostPool
- Randomness manipulation in GhostDraw
- Client-side cryptographic authorization flaws

Please **DO NOT** create a public GitHub issue.

### Disclosure Process

1. Email the core development team or open a private GitHub security advisory.
2. Provide detailed steps to reproduce the issue, including proof of concept code if available.
3. Allow the core team reasonable time to investigate, remediate, and deploy a fix before public disclosure.

We appreciate your responsible disclosure in keeping the protocol secure.
